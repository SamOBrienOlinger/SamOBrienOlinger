# Together Sans

Together Sans v0.1 is a modified version of Inclusive Sans by Olivia King and
the Inclusive Sans Project Authors. The adaptation widens letterforms by 2.5%
and adds 4 font units of space to each side of positive-width glyphs.

This directory contains the Light (300), Regular (400), Medium (500), and
Bold (700) WOFF2 web fonts. They are self-hosted and loaded by `styles.css`.
The main hero heading retains the site's original system font.
